## v1.9.0 - July 30, 2026

DevThrottle speaks French and Spanish, the install instructions describe what actually ships, and
several things that failed quietly now say so.

### DevThrottle speaks French and Spanish

What is translated is what DevThrottle SAYS. The on-screen text is not translated, deliberately and
for now - so an account set to French hears French and reads English.

- **Pick a language and everything spoken follows it.** DevThrottle speaks from four places - the
  narration of what a session just did, the direct reply when you ask it something, the in-product
  help, and the assistant. Each used to carry its own copy of the speaking rules, so a language could
  reach one of them and not the others; an account set to another language got translated narration
  and English everywhere else. There is now one place those rules live, so a language reaches every
  spoken path by construction rather than by somebody remembering.
- **English is unchanged unless you choose otherwise.** Any account that never opens the new Language
  tab speaks English exactly as before.
- **The voices are not evenly matched, and the screen says so.** English has twenty-eight voices,
  Spanish three, French exactly one. That is a real asymmetry rather than an oversight.

### Car Mode is not in this release

- **Car Mode is out of the product for now.** The assistant that shared its underlying brain stays -
  that part was never Car Mode's, and it is the same thing that answers you in the app. What has gone
  is the Car Mode surface itself.

### Things that failed quietly now say so

- **A prompt that was never delivered is surfaced instead of whispered into a log.** If something you
  sent to a session did not arrive, that was previously recorded where nobody would look, so the
  session simply appeared not to answer.
- **The Gateway no longer claims a timed-out command did not run.** A command that timed out was
  reported as not having run, which is a different and stronger claim than "no answer came back in
  time" - and often untrue, because the command was running when the clock ran out.
- **A session that is already dead cannot be snoozed.** Snoozing one used to appear to work.

### Setting up and running

- **The install instructions describe what actually ships.** They are rewritten against the real
  two-step install, and the download page is quoted rather than paraphrased, including which route is
  not account-free.
- **The setup wizard launches the agent program it recorded**, not a bare command name that might
  resolve to something else or to nothing.
- **A held session can be listed, so a leftover card can be cleared.** A held session was invisible to
  the thing that reaps stale cards, so the card stayed on your screen with nothing behind it.

### Housekeeping

- **One browser automation tool has been removed from what gets installed.** It was shipped in the
  toolbelt and is no longer part of it, so a new install is smaller and has one less thing to keep
  current.
