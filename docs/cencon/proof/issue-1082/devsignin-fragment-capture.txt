Dev sign-in stand-in (local stand-in for the devthrottle.com completion page) now hands the
credential back in the URL FRAGMENT, not the query string (issue #1082).

Request:
  GET http://127.0.0.1:8799/complete?provider=google&redirect_uri=http://127.0.0.1:56000/devthrottle-login-callback/

Response:
  302 Found
  Location: http://127.0.0.1:56000/devthrottle-login-callback/#access_token=<ACCESS_JWT>&refresh_token=<REFRESH>

  query part (before '#'): http://127.0.0.1:56000/devthrottle-login-callback/   <-- EMPTY query, no token
  fragment part (after '#'): #access_token=<ACCESS_JWT>&refresh_token=<REFRESH>  <-- browser never sends this to the server
