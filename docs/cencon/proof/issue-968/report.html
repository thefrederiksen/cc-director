What was implemented

Created the one shared TypeScript library both browser shells will depend on and proved it with a working consumer by moving the mobile app onto it, removing the existing duplication immediately.

  • An npm workspace at the repository root (package.json "workspaces": ["packages/*", "apps/*"]).
  • The mobile app moved mobile/ → apps/mobile (a thin shell: screens, routing, styles). All moves are git renames, so history is preserved.
  • The six shared concerns promoted into packages/client-core (source of truth moves): api (the typed Gateway client + generated schema.ts), history, terminal, dictation, auth, sessions. The app imports every shared concern from @devthrottle/client-core and keeps no copy.
  • The package exports TypeScript source (the exports map points at src/), so Vite and tsc resolve it with no separate build-ordering step. It also has its own standalone typecheck and declaration build.
  • gen:api moved into the package; the C#-DTO single-source-of-truth guarantee is preserved.
  • A Gateway-only-ingress ESLint rule (eslint.config.js) bans absolute http/https/ws/wss literals across packages/** and apps/**, with one documented exception (the public devthrottle.com sign-in site).
  • The Gateway BuildMobileApp MSBuild target now installs/builds through the workspace root and stages apps/mobile/dist into wwwroot/m.

CenCon impact

No architecture or security drift. This is a front-end source reorganization plus a lint rule; it introduces no new container, no new network ingress, and no change to the Gateway-only topology - it enforces that topology in client code. The security_profile.yaml blocking rules (DT-*) are unaffected. The one intended absolute-URL egress (the public devthrottle.com sign-in site) is unchanged and now carries a documented inline exception.

Conclusion

I believe this is finished.

All four acceptance criteria are met and proven: packages/client-core builds and type-checks standalone; apps/mobile consumes every shared concern from the package with no remaining copy and still type-checks and builds; the gen:api DTO guarantee is preserved; and the Gateway-only-ingress lint rule is active with the whole workspace green.
