Issue #942 - Out-of-credits UX on the mobile PWA voice surfaces

Part of epic #937. The live mobile app is apps/mobile (React over packages/client-core). The Gateway /wingman/* endpoints already return the shared 402 (from #939), so this is client-side.

Approach (one chokepoint, no per-surface duplication)

Every Gateway call funnels through packages/client-core/src/api/client.ts, which throws a GatewayError on a non-2xx. The mobile app had ZERO out-of-credits handling. The fix makes a hosted-AI 402 produce a typed CreditsError whose message IS the shared text - so every surface's existing err.message banner shows the correct copy by construction - and also emits the shared body to ONE app-level notice that renders the "Add credits" call-to-action. No surface had to widen its error state.
