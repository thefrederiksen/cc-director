What I am unsure about, so you know where to push back

  • Whether "Rules" belongs in the left rail at all. It might sit under Settings as a tab. I put it in the rail because it is a thing you visit and read, not a preference you set once - but that is a judgement, not a finding.
  • Whether the words-to-watch-for box should be visible. It is a cost control that most people would leave empty. Hiding it behind "advanced" is cleaner, but then nobody discovers the one lever that stops a rule being asked about every screen.
  • Whether "Save and go live" should exist on a new rule. The safe answer is that every new rule starts in dry run and can only be promoted after it has matched something. That is slower and it is probably right.
  • The list has no history view yet. Every match and every action is recorded; that wants its own screen, and it is not drawn here.
