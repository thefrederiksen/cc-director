## Phase 1 design (chosen approach)

Generic command envelope down the existing stream, flag-gated, HTTP fallback preserved:

- Contract: `DirectorCommand { Verb, SessionId, PayloadJson }` + `DirectorCommandResult { Ok, StatusCode, BodyJson, Error }` in `CcDirector.Gateway.Contracts`.
- Director side: `GatewayStreamClient` registers `On<DirectorCommand, DirectorCommandResult>("Command", ...)` -> a dispatcher that reuses the SAME in-process handlers the Control API endpoints call (shared-handler pattern, mirroring the shared SessionDto mapper from 1a). NO re-dialing HTTP to itself.
- Gateway side: `GatewayHost.SendCommandAsync(directorId, cmd)` via `IHubContext<DirectorHub>` + active connection id (exactly like `PingDirectorAsync`). A routing helper: when streamMode on AND the Director has an active stream connection, send the command DOWN the stream; else fall back to `DirectorEndpointClient` HTTP.
- One verb at a time, each with a test, additive.
