3. What to do first - ranked action list

Split into two lanes: land what is already written (highest leverage this week), then start new work that is still missing or wrong.

Lane A - land existing work (do this before opening more large units)

A1
Merge the census + remedy map (#1936) Workers and reviewers keep reading a specification that is not on main. That has already cost time. This is documentation only and unblocks everyone.
A2
Merge the shared hosted refusal primitive (#1951) Every deny family should use one boundary. Landing this first makes later deny pull requests rebasable onto one shape instead of five slightly different filters. Green on both build lanes.
A3
Merge the deny family (security floor) In roughly this order once A2 is in: #1898 (settings / AI models / telemetry consent), #1904 (vault), #1903 (content reads), #1907 (recording + voice read), #1939 (launcher / machine), #1940 (transcription provisioner pin). These close active public-signup attack paths. Prefer rebasing each onto #1951 if they still roll their own filter.
A4
Merge authorize + partition greens #1930 (stream ownership), #1899 (hashed device keys), #1935 (netdiag), #1933 (car-mode telemetry), #1909 (composite primary keys), then #1906 (database route proof, after #1909).
A5
Rebase the conflicted upload pair (#1945, then #1900) Both touch VoiceUploadStore. #1945 makes an unscoped store impossible to construct; #1900 tenant-keys dictation. Conflicts mean they will rot if left open while denys land. Rebase is work; rewriting is not.

Lane B - new work that is still missing or incorrectly implemented

These are the items that should actually be started as new implementation once Lane A is moving - ranked by risk and by whether anything already covers them.

1
Session-identifier family: adopt TenantSessionMap (14 census rows) Highest new-work priority No pull request

Foundation shipped (#1934). Production still uses bare session strings for needs-you, both transcribing maps, governance state emitter, turn-end watcher, turn-brief caches, fanout rate budget, and more. This is the largest remaining active-unsafe work unit in the remedy map. Incorrect state: types exist and look finished while the Gateway still collides.

Start shape
One derivation helper after RequireBoundTenant / ResolveReadTenant. Convert stores in small batches (e.g. needs-you + both transcribing marks first; then turn briefs; then governance / fanout). Every batch needs a two-tenant same-raw-id collision test. Do not rename external session identifiers.

2
Voice routes and background loops still hard-code Local Incorrectly implemented No full fix pull request

Voice state is partitioned (#1915). Voice call sites still pass TenantId.Local (~19 hits in GatewayWingmanVoiceEndpoint). That is the classic half-fix: the store is multi-tenant; the product path is not. Background loops (#1893) same bug. #1907 correctly denys some hosted voice reads as an interim floor - that is not a substitute for making generation tenant-correct.

Start shape
Resolve request / bound-connection tenant on every voice route; drive background generation through ITenantPass. Keep synthesis key out of the vault until a two-account live proof passes. Pair with session-key adoption for any remaining bare session marks the voice path touches.

3
Statistics identity bundle + concurrency scalars (12 census rows) Missing No pull request

Eleven identity maps (repository / agent / model / checkout) plus concurrency hour and process-wide scalars still fold every tenant into one shared statistics world. Stats dashboard is already denied on hosted (#1888), so this is not the loudest public leak - but push-time aggregation still mixes tenants in memory and on disk, and any future per-tenant stats product will ship wrong numbers if this is left.

Start shape
Pass authenticated tenant into both aggregator call paths from DirectorHub and roster fold. Partition all identity maps and the concurrency tracker by tenant. Migrate legacy database mirrors with the memory maps in the same unit.

4
Complete the Director-removal family (incorrectly incomplete) Partial fix on main

#1942 fixed the event payload and roster forget. Still broken or incomplete:

  • FleetSessionNumberAllocator.ReleaseForDirector still drops the tenant (census row 24)
  • Hosted snooze clear still skipped on removal
  • Raw tenant GUID still logged on removal / forget
  • _everReachable / _stateReporting still bare Director ids

Start shape
One small pull request: tenant-scope the allocator end-to-end (allocate, adopt, release, removal), re-enable hosted snooze clear with tenant, and switch logs to ToLogString(). High leverage, low design risk - same pattern as #1942.

5
Residual bare Director-id routes (#1866) + HTTP register on hosted Still active No pull request

Composite registry keys only help callers that pass a tenant. Legacy Get(string) / TryResolveLegacyKey still pick the freshest match across tenants. Credential-less HTTP register still stamps Local and pollutes bare-id resolution. This is residual of a closed issue (#1847) that never finished the route conversion.

Start shape
Inventory remaining bare-id callers; convert each to request/bound tenant; on hosted refuse HTTP register/heartbeat entirely. One route family per pull request if needed.

6
Remaining remedy units without pull requests Missing
  • Director event rings (census row 23)
  • Cron _inFlight overlap lock (row 13)
  • Machine-name family beyond the hosted deny (rows 14, 42, 66, 69) - permanent design is #1938
  • Broadcast rate budget + grant ownership (rows 1-2)
After items 1-5, cut these from the remedy map one work unit each. Do not invent a parallel plan - the map already has the ingestion points.
7
Hosted mode fail-closed (#1868) Config footgun Losing CC_GATEWAY_HOSTED collapses isolation silently. Small independent unit: image-baked hosted marker or refuse boot when multi-tenant schema is present without hosted mode. Can ship in parallel with larger work.

4. What not to start yet

  • Enabling voice synthesis on hosted - routes still Local; denys and partitions for speech paths are incomplete. The QA warning still stands.
  • Enabling the self-host card - orchestrator is good; real-machine proof is not done. A half-provision is worse than a disabled card.
  • Per-tenant stats product (#1886) - blocked until the statistics identity bundle is partitioned and attribution exists.
  • Permanent tenant-scoped launcher (#1938) - the interim deny (#1939) is the right floor; do not rebuild launcher multi-tenancy until denys are on main.
  • Opening more deny families that re-roll their own filter - use #1951 after it lands.

7. Bottom line

Much more is implemented - in open pull requests, not on main. The program has the right census, the right remedy map, and a large deny/partition wave ready to land.
The most important things to start that are still missing or wrong:
  1. Adopt TenantSessionMap into the fourteen session-keyed stores (missing).
  2. Stop hard-coding Local on voice routes/loops (incorrect half-fix).
  3. Partition statistics identity + concurrency (missing; 12 rows).
  4. Finish Director-removal fallout - session numbers, snoozes, logs (incorrect half-fix).
  5. Convert residual bare Director-id routes (missing).

And before those, merge the green isolation pull requests - that is the highest leverage work already sitting done.
