The mismatch the bug

The card and the screen are different features

The card says "Run your own gateway and join it" and the button says "Set up self-hosted". What opens is a scanner that finds gateways already running and connects to one.

Provisioning a gateway on this machine is not built. So the card promises something that does not exist, and the thing it actually does - joining a gateway you already have - has no card of its own and no name anywhere on the screen.

Why it matters to you specifically. You run more than one named Director on a machine, pointing at different gateways. That is a join. It is the option the wizard never names - it is hidden behind a card advertising an unbuilt feature.

What actually changes in the code

The middle card's title, its one line of description, and the button label when it is selected. The behaviour behind it does not change at all - it already opens the scanner; it will just no longer be advertised as something else.

Half an hour, not half a day. My earlier estimate was for rewiring the whole step through shared code, which is a bigger and separate question - and not what this fixes.

The one thing this does NOT decide

Whether "run a gateway on this machine" ever gets built. It is not built today, on any screen. Removing the promise from this card does not remove the feature - there is no feature to remove. When it is built, it gets a card that works.
